# 3D 地图路径规划

低空航迹规划与仿真平台的独立工作台模块。基于天津大学卫津路校区周边建筑数据，提供长方体城市编辑、三维航线计算和多机时间协调。

## 使用

在平台“分析工作台”选择“3D 地图路径规划”。

1. **飞行任务**：设置地面或屋顶起终点，填写速度、高度上限和避障间隔，计算三维航线。
2. **多机协同**：填写相对模拟开始的出发秒数，将当前航线加入队列，或载入三机交会示例。
3. 播放共同时间轴。点击任务编号突出对应航线；在地图下方展开配置与协调记录。任务可移除，剩余任务重新协调。
4. **地图编辑**：增加、移动、删除建筑及修改楼高；用两个对角点绘制带高度上下界的矩形禁飞区。
5. **视图**：切换地图范围、俯视、楼高配色和显示倍率。顶部菜单可收起或固定；窄屏横向滚动功能区，展开后地图向下移动。拖动地图底边调整显示高度。
6. **测试与导出**：运行范围性能测试、导出单机方案。多机菜单可导出完整任务、参数、航点、时刻、等待原因与场景修改。

单机采用分层 A*，水平网格 25 / 50 / 100 m、高度层间隔 30 m，并包含指定高度上限。搜索目标是离散运动模型下的飞行时间。每条边与扩张后的旋转建筑包围盒及禁飞区做连续线段相交检查；不使用未经检查的曲线平滑。上升与下降速度一致，水平段匀速，转弯为折线。

多机按加入顺序保持前序任务优先。检查分段线性轨迹的连续相对运动：只有水平与垂直间隔同时不足才判为冲突，包括起降阶段。默认机间水平间隔 50 m、垂直间隔 30 m；后加入任务以 5 秒为步长推迟起飞，最多延迟 2 小时。支持最多 12 架飞机。当前策略是地面等待，不是空中悬停，也不对已计算航线重新选路。地面停放不计为空域占用，不建模停机坪容量。

三机示例中，第二架沿第一条航线反向飞行，第三架独立计算南北航线。这用于明确展示同航线对向冲突的时间协调，不代表三条独立最优路线必然冲突。在默认参数下，该示例第二架等待 160 秒，其他两架按期望时刻起飞；参数或场景改变后结果重新计算。

每架任务保存入队时的参数。修改单机参数和起终点不会改动已安排任务；修改建筑、禁飞区、恢复或更换地图会清空队列，避免回放过期方案。调整机间间隔会重新调度。任务暂存在页面内存中，刷新前可导出 JSON。

## 城市数据

| 范围 | 建筑数 |
| --- | ---: |
| 3 × 2 km | 3,101 |
| 5 × 5 km | 14,624 |
| 10 × 10 km | 49,304 |

来源为 Zheng, Yue; Zhang, Xucai; Liu, Geng; Che, Yangzi; Zeng, Youli; Yi, Yan; Zhuang, Caigang; Liu, Xiaoping 发布的 [CBMF: the building main function dataset of China, v2](https://doi.org/10.5281/zenodo.18595960) 天津地理数据库，采用 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 许可。许可于 2026-11-18 通过 Zenodo 记录元数据核实。源数据高度来自 [3D-GloBFP](https://doi.org/10.5281/zenodo.11397014) 的估计值。

本模块对数据进行了范围裁剪、EPSG:32650 投影转换、局部坐标变换和最小旋转外接矩形简化；不发布完整原始地理数据库。坐标单位米，x 东、y 高度、z 南；地面为平面。矩形简化会填平凹形建筑，估计楼高不等同于逐栋实测。垂直展示倍率仅改变画面，不改变规划计算。

当前未建模地形起伏、道路与人口风险、风场、飞行动力学、外部航空器及真实空域。Three.js 依赖许可见 `vendor/LICENSE`。

## 验证

- 单机：旋转建筑相交、爬升越障、高度上限、禁飞区绕行、屋顶起降、无效参数，以及三档天津地图航线的整条复核。
- 多机：同高交叉、对向、垂直分离、亚秒级交会、删除重排、无效输入；默认天津三机示例通过连续轨迹检查及独立 0.2 秒抽样复核。
- 控制器：规划、入队、回放、拖动时间轴、参数快照、任务移除、场景失效、计算取消、菜单展开和收起。

纯算法测试无需安装依赖：`node planner3d/test-planner.mjs` 与 `node planner3d/test-fleet.mjs`。浏览器 WebGL 画面须在实际访问时检查，程序化控制器测试不替代画面验收。
