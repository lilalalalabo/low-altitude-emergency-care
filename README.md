# 低空航迹规划与仿真平台

**Low-Altitude Flight Planning Lab**

面向低空航线规划与空间计算的研究型原型，探索障碍规避、航迹设计、飞行仿真和多任务协同方法。

**在线访问：** [低空航迹规划与仿真平台](https://lilalalalabo.github.io/low-altitude-emergency-care/)

## 当前进展

平台处于早期开发阶段，支持中英文切换、单机路径规划和示意飞行播放。用户可设置起点、终点、出发时间，以及巡航高度、水平速度和起降速度。A–D 型号提供可修改的示例参数；切换型号会载入相应初始值。

工作台使用虚构的 24 × 16 城市网格，每格边长 50 米。路线搜索使用八方向网格 A*，以网格中心之间的距离为成本，并禁止斜向穿越障碍物角点。示例禁飞区在所有高度均不可通过；示例建筑只有在巡航高度高于建筑高度 10 米以上时才可飞越。起点和终点不得位于建筑或禁飞区内。上升与下降共用用户设定的起降速度。

每次规划会记录该任务的参数；队列中的任务独立计算，尚不进行任务间冲突检测，刷新页面后不保留。动画以模拟时间的 20 倍速度播放。结果是该离散模型中的最短路线，没有模拟水平安全缓冲、真实地形、飞行性能或其他航空器。

**城市、建筑、禁飞区及飞机参数均为示意数据，不适用于真实飞行。**

## 后续方向

- **真实空间数据接入：** 探索在合法使用条件下接入道路、建筑和地理空间数据，并记录数据来源及适用范围。
- **多机任务协调：** 将既有任务的轨迹和时间转换为动态空间约束，探索后续任务的避让与时间协调。
- **场景与约束管理：** 研究不同高度、不同时间的飞行约束，并支持自定义示例区域和规划参数。
- **方案比较与可视化：** 比较航线长度、模拟时长和不同参数配置下的规划结果。
- **方法记录：** 保留数据口径、假设和算法说明，为后续研究与案例复核提供依据。

以上为拟开发方向，具体实现范围将随数据和研究进展调整。

## 武汉城市设施案例

数据案例使用 [GeoClaw 武汉开放数据集](https://github.com/whuyao/GeoClaw_Claude/tree/main/data/wuhan)的医院及卫生设施点位和行政边界。来源项目说明数据提取于 2026 年 3 月。原始 200 条记录中，146 条位于同一数据集的武汉边界内，经点与多边形空间匹配后用于展示。案例按照是否有名称对样本着色；这些点仅用于展示空间数据，不能据此推断飞行条件。样本可能不完整或过时。

数据及边界 © [OpenStreetMap 贡献者](https://www.openstreetmap.org/copyright)，依据 [开放数据库许可证 ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) 提供。所提供的案例文件为精简版本，行政边界仅用于研究可视化，不作为法定边界依据。
